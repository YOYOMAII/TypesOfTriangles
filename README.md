# Types of Triangles

This project is a Windows Forms app that takes three side lengths and shows whether the triangle is equilateral, isosceles, scalene, or not valid.

**Team:** Hein Htet Oo / Aye Thawdar / Min Bhone San / Lin Htut Khine / Htet Wai Yan / Hein Ko Ko San / Myo Khant Kyaw / Zue Zue Hlaing / Myat Noe / Pyae Sone Aung

## Credit

Special thanks to **Lin Htut Khine** for writing the core triangle-type logic (valid triangle check and Equilateral / Isosceles / Scalene classification).

Run (Windows, from the project folder):

```
msbuild TypesOfTriangles.csproj /p:Configuration=Release
bin\Release\TypesOfTriangles.exe
```
